# HIGH / LOW
A simple console gambling game developed by Malcolm.

Made with visual studio 2026 community edition.

<img width="301" height="182" alt="image" src="https://github.com/user-attachments/assets/defa73a0-2680-4085-a798-0984ee0196a8" />

Rules: Out of 100 guess if the random number will be 51 - 100 (HIGH) or 1 - 50 (LOW)

Controls: Type numbers when the program prompts you and press enter to submit
